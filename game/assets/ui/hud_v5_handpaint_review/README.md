# Independently generated GPT Image HUD draft sprites (review only)

These sprites are cleaned and normalized **from separately GPT Image-generated PNGs** (earlier turns, one icon at a time), not from the SVG raster process and not cropped out of a collage.

They are **candidates**, not individually approved screenshot-faithful final assets. Title utility glyphs have been recolored to match the off-white screenshots; accidental alpha speckle was trimmed. Full original canvas sizes and resource slugs are retained, but each image MUST be re-compared against the user's screenshot at original display resolution.

Do NOT automatically replace the existing production HUD with these candidates.
