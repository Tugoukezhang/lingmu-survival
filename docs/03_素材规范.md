# 素材规范（给美术 / AI 出图用）

版本：0.2｜日期：2026-11-08｜v0.2：远征岛是随机生成的，改用「拼接地块 + 摆件」，新增夜晚与生存类素材

## 通用要求
- **不要水印**、不要签名、不要 UI 叠在画面上。
- 单个物体：**纯白底或透明底**，物体完整不被裁切，四周留 10% 空白。
- 格式 PNG；同一类素材视角、光照方向（左上方来光）、描边粗细保持一致。
- 视角：固定 3/4 俯视角（和风格示例的房间、小镇一致）。

## 命名
`类别_名字_状态_序号.png`，全部小写英文和下划线，例如：
- `pet_fox_idle_01.png`、`pet_fox_attack_01.png`
- `player_down_walk_02.png`
- `crop_pumpkin_stage3.png`
- `item_berry.png`、`furn_sofa_green_front.png`
- `bg_farm.png`

ID 与 `docs/02_宠物战斗与数值.md` 一致（mochi、turtle、otter、owl、fox、bunny）。

## AI 出图流程（2026-11-08 确认）
- 用 GPT Image 2.6 出图，每次附风格示例图当参考图；提示词和流程见 `09_AI出图提示词.md`。
- 原图放 `art/raw/`（不提交），处理后的素材放 `game/assets/`（提交）。
- 不达标：AI 给出具体问题和改好的提示词，负责人重出；抠图、调色、尺寸、接缝等后期问题由 AI 直接修。

## 为什么远征岛要拼接地块
远征岛每次随机生成，没法用一整张手绘背景。做法是把手绘风格的地面切成可以重复拼接的小方块，程序按生成结果铺地面，再把树、石头这些手绘摆件放上去。效果取决于地块接缝是否自然，所以先出一组草地地块试拼，确认没问题再出全套。
