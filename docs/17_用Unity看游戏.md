# 用 Unity 直接看游戏（不用再等网页包）

以前想看最新效果，AI 要打一次网页包，大约 43 分钟。现在电脑上有一份专门给负责人看的游戏副本，用 Unity 打开、按播放键就能玩到最新版本。

## 第一次打开

1. 打开 Unity Hub，左边点「项目」。
2. 点右上角「添加」旁边的小箭头，选「从磁盘添加项目」。
3. 选择文件夹 `D:\lingmu-play\unity`，点确定。
4. 列表里出现这个项目后，点它打开。
   - 如果提示「编辑器版本未安装」：点版本号旁边的按钮选「定位」，找到 `D:\Program Files\Unity 6000.3.28f1\Editor\Unity.exe`。
5. 第一次打开要等几分钟。
6. 在下方「Project」窗口里打开 `Assets/Scenes`，双击 `Title`（标题页）。
7. 点窗口最上面中间的 ▶（播放键）开始玩。再点一次停止。

## 操作

| 做什么 | 键盘 / 鼠标 |
|---|---|
| 走路 | W A S D 或方向键；也可以在画面左边按住拖动（摇杆） |
| 转视角 | 在画面右边按住鼠标拖动 |
| 互动（采集、聊天、睡觉等） | E 或空格；也可以点右下角的大按钮 |
| 背包 / 制作 / 地图 | B / C / M |
| 关掉面板 | Esc |

## 要注意

- 这份副本只用来看，不要在里面改东西。AI 更新时会直接覆盖它。
- AI 每次做完一批改动，会把这份副本更新到最新。Unity 开着也没关系，切回 Unity 窗口时它会自动加载新内容。
- 想重新从头玩：游戏里「设置 → 回到标题页 → 新的开始」。
- AI 平时用另一份工程（桌面上的 `lingmu-survival`）做开发和测试，两份互不影响。
