# 第二轮 · 高精度重做（Tripo 网页，2026-11-21）

负责人 11-21 试玩后的意见：
- 主角"实在是太劣质了"；
- 宠物动作、战斗动作要优化；
- 树木精度不够、也不会动；
- 「先把界面和模型做完……精度一定要高」。

**为什么旧模型不好**：原图大多是坐着、挥手、手里拿着东西的 2D 插画。照这样的图生成的模型，四肢粘在身体上，绑骨骼后动作别扭；生成时用的 Tripo 版本也旧。

**这次的做法**：GPT 照原来的角色重新画了建模专用图。
- 统一成和主角一样的"黏土 / 毛毡玩偶"3D 质感；
- 标准站姿：人形是 A 字站姿，四条腿的宠物四腿分开站好；
- 手里不拿东西、嘴闭着微笑。

**谁来操作**：负责人已登录 Tripo 网页，AI 通过 Chrome 插件（Claude in Chrome）操作，用网页会员积分。用单张图片生成（负责人以前都这样做）。

## 生成设置（每个都一样）
- 模型版本：网页上**最新、质量最高**的那个。
- 贴图：**高清 / HD 或 4K**；**不要 PBR**。
- 面数：角色和宠物 **3 万面**左右，树 **2 万面**左右（网页能填就填；只有"高 / 中 / 低"就选高）。
- 每个生成后转一圈检查：脸、四肢是否分开、背面、配饰（帽子、围巾、背包）。不像就重新生成，挑最好的那个。

## 骨骼和动作
- 先点「检查」，以网页建议的骨骼类型为准。人形的预设选 **Unity Humanoid Compatible**（没有就选 Mixamo）。
- 动作都选「原地 / In place」。

| 谁 | 动作 |
|---|---|
| 主角 | 必须：待机、走、跑。有就加：挥砍（砍树）、弯腰捡、扔、欢呼、跳、受击、倒下 |
| 宠物 | 必须：待机、走、跑。有就加：攻击 / 扑、受击、倒下、开心 / 跳、坐下 / 趴下睡觉、吃东西 |
| 居民 | 待机、走、挥手 / 打招呼、说话 / 点头 |

网页上找不到的动作，AI 在 Blender 里补；战斗里的前冲、受击闪色、击退在游戏里用程序做。

## 下载
- 格式 **FBX**，贴图「打包 / embed」。
- 带骨骼的，**一定在绑好骨骼、带动作的那个结果上下载**。上次从「转换」下载的文件里没有骨骼。
- 树只要模型本身（FBX 或 GLB 都行）。

## AI 接手后
检查骨骼和动作，修方向、大小、贴图，导入 Unity，换掉旧模型，接上各个动作，截图给负责人看。网页的骨骼要是出问题（倒过来、歪着），AI 自己在 Blender 里重新绑。树在游戏里加随风摆动（已做好）。

## 积分（以网页为准）
每个模型生成约 100–200，绑骨骼约 25，每个动作约 10。13 个全做大约 2500–3500。按顺序做，做到哪算哪。
