# 第二轮 · 主角重做（在 Tripo 网页上做，2026-11-21）

负责人 11-21 试玩后说主角"实在是太劣质了"，要重做。
旧模型的毛病有两个：
- 原图是挥手的姿势，绑出来的骨骼和走路动作都别扭；
- 当时的 Tripo 版本也旧。

这次 GPT 照原来的主角画了标准站姿（A 字站姿：手臂自然下垂、离开身体一点）的四张图，放在 `图片/第二轮_主角/`：

| 文件 | 用途 |
|---|---|
| 1_正面.png | **主要用这张** |
| 3_背面.png | 多视图时用 |
| 2_侧面朝左.png / 4_侧面朝右.png | 多视图时用（角色脸朝画面左边 / 右边） |

## 步骤（每一步网页上找不到按钮，就截图发给 AI）

**1. 生成模型**
- 进 Tripo 网页的「图片生成 3D」（Image to 3D），上传 `1_正面.png`。
- 模型版本：选列表里**最新、质量最高**的那个（一般带 P2 / P1 / v3.1 字样，以网页为准）。
- 贴图：选**高清 / HD**（有 4K 选 4K 也行）。**不要勾 PBR**。
- 面数：如果能填，填 **30000**（主角离镜头近，可以多给一点）。没有这个选项就用默认。
- 生成后转一圈看看，挑最像原图的：**脸、帽子上的叶子和扣子、背面的背带**。
- 不满意可以重新生成；如果背面很怪，换「多视图」（Multi-view）模式，把四张图按网页示意放进对应的格子再生成一次。

**2. 绑骨骼**
- 在生成好的模型上点「绑定 / Rig」（先点「检查」，以网页建议为准）。
- 类型选**人形 / Biped**；骨骼预设选 **Unity Humanoid Compatible**（没有这个就选 Mixamo）。

**3. 加动作**（一个一个加，选「原地 / In place」）

| 优先 | 动作 | 游戏里用在哪 |
|---|---|---|
| 必须 | 待机 idle | 站着不动 |
| 必须 | 走路 walk | 走 |
| 必须 | 跑步 run | 推摇杆推到底 |
| 有就加 | 挥砍 / 砍 slash / chop | 砍树、敲石头 |
| 有就加 | 弯腰捡东西 pick up | 采集、捡东西 |
| 有就加 | 扔 throw | 扔网抓宠物 |
| 有就加 | 欢呼 / 挥手 cheer / wave | 抓到宠物、完成任务 |
| 有就加 | 跳 jump | 以后用 |
| 有就加 | 受击 hit / hurt、倒下 fall | 被雾怪打、晕倒 |

**4. 下载**
- 格式选 **FBX**，贴图选「打包 / embed」。
- **一定要在绑好骨骼、带动作的那个结果上下载**。上次从「转换」（convert）下载的文件里没有骨骼。
- 每个动作单独下载也可以，文件名随便，AI 会认。
- 全部放进 `完成的模型放这里/主角v2/`，然后告诉 AI「主角做好了」。

## AI 接下来做什么
- 检查骨骼数量和动作，修方向和大小，压缩贴图，导进 Unity，换掉旧主角。
- 给每个动作接上对应的操作（砍树、扔网、欢呼……），截图给负责人看。
- 网页的骨骼要是又出问题（倒过来、歪着），AI 自己在 Blender 里重新绑。

## 积分
大约：生成 100–200 + 绑定约 25 + 每个动作约 10。以网页显示为准。
