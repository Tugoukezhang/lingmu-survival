## 2026-11-08｜T08 存档基础

**做了什么**
- `systems/save.js`（纯逻辑，可在 Node 里测）：整个进度是一个 JSON 对象（天数、时间、四叶草、玩家生命/饱食/位置、背包、全部宠物实例、队伍、远征信息预留）。存成「校验码|内容」，内容被截断、乱改都能发现。
- 每次存档先把上一份**完好的**存档复制为备份；主存档坏了自动读备份，两份都坏才开新档，并提示玩家。坏掉的主存档不会覆盖掉好的备份。
- 版本号 + 迁移函数表（以后改存档格式时加一步迁移）；更新版本游戏写的存档会另外保留，不会被旧版本覆盖。
- 对战、倒下动画期间可以挡住存档（`block('battle')`），给 T06、T20 用。
- 浏览器不允许存储（隐私模式）或空间满时不报错，提示「进度不会保存」。
- `systems/GameSession.js`：启动时读档；HUD 数值通过 registry 显示；自动存档 = 每 20 秒（有变化才存）+ 切到后台 + 关闭页面；换同行宠物时立即存。
- 接入：宠物面板、背包面板改读存档里的真实数据（物品定义搬到 `data/items.js`）；世界里的宠物、同行宠物、焰尾狐形态、玩家位置都从存档恢复；设置面板显示「进度自动保存 · 上次时间」，「重新开始」真正清档重来。
- 新档内容（演示用，等开局三选一做好再换）：6 只宠物都在家园岛，冰蓝小狼同行，背包 3 种物品，四叶草 120。

**验证**：逻辑检查新增 24 项（共 77 项全过）：存取一致、存档不含属性值、备份轮换、截断/篡改/乱码/空内容/内容不合法 → 读备份、两份都坏 → 新档、坏档不覆盖备份、对战中不存、存储写满不报错、更新版本存档另存、迁移函数与缺迁移时拒读、重新开始清档。浏览器检查新增 6 项（共 29 项全过）：刷新后四叶草、位置、同行宠物保留；关闭页面自动存档；手动改坏存档后刷新从备份恢复并提示；设置里重新开始。T08 状态：待验收。
