## 四、做法和顺序

1. **零件总览**（1 张）→ 给负责人看风格 → 定稿。
2. **零件组图**（约 12 张）→ 裁切、九宫格、接进 `UiKit`（以后所有面板换皮只改 `UiKit` 的画法，面板代码不动）。
3. **逐屏改版**，按 P0 顺序：主界面 → 背包 / 仓库 / 出货 / 商店（同一套）→ 伙伴 / 图鉴 → 对战 → 制作 → 居民 → 日报 / 每日任务 → 码头 / 营火 / 确认框 / 庆祝卡 → 地图 → 标题页（等名字）→ 布置。
4. 每屏改完：流程测试截图 → GPT（gpt-6.2-astra）从"手游玩家第一次看"的角度审 → AI 筛选意见后改。
5. 动效和手感：面板 0.2 秒弹出、按钮按下缩放、红点呼吸、获得物品飞入（和逐屏改版一起做）。
