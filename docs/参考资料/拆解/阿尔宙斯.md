# 宝可梦传说 阿尔宙斯 流程拆解

## 骨架
- **主线任务 + 支线委托**【摘录】：主线任务推进剧情，基本按顺序做（偶尔同时开放几个）；支线委托是抓宝可梦、帮村民的小事。
- **队员星级开新区域**【摘录】：图鉴调查攒研究点数 → 提升调查队星级 → 开放新区域；星级也决定多高等级的宝可梦肯听你的【已核对：52poke】。
- **每个区域一只「王 / 女王」**【摘录】：剧情里有 5 只被庇佑的强大宝可梦，会狂暴，要玩家去镇抚；镇抚后得到一块石板，之后还能骑乘对应的宝可梦移动（陆地、水上、空中）。
- **图鉴调查**【摘录】：每种宝可梦有若干课题（抓几只、打倒几只、看它用某招、喂食……），普通课题 10 分、加倍课题 20 分，满 100 分 = 调查等级 10（完成），完成一种额外给 100 点研究点数。
- **最终目标**【摘录】：抓到全部非幻之宝可梦后，用笛子去神殿见阿尔宙斯。

## 节奏和数字
- 本作 242 只宝可梦【已核对：52poke】。
- 主线通关约 20–30 小时；算上支线约 40–50 小时【摘录】。
- 区域 5 个（黑曜原野、红莲湿地、群青海岸、天冠山麓、纯白冻土）【待核对】。
- 1.1.0 更新加入通关后的连战挑战【已核对：52poke】。

## 野外玩法（和我们 ③ 野外扔网直接相关）
- 可以不进对战直接扔球；没被发现时扔中、从背后扔中成功率大涨。可以躲在草丛、岩石后面，或用烟雾靠近【已核对：52poke + 摘录】。
- 胆小的宝可梦发现你会跑，好斗的会主动攻击玩家，玩家可以翻滚躲开，或者派自己的宝可梦迎战【已核对：52poke】。
- 在野生宝可梦没发现时开战，玩家先多行动一回合【已核对：52poke】。
- 头目宝可梦：体型大、眼睛发红、带稀有招式，会主动攻击玩家【已核对：52poke】。
- 玩家倒下会掉一部分道具，变成「失物包」，只能等别的玩家帮忙捡回【摘录】。

## 对我们有用的
- **「调查等级 → 星级 → 开新区域」是现成的解锁骨架**：我们的 ④ 图鉴调查可以直接接到「研究员星级」，星级决定飞艇能飞多远。
- **每个区域一只镇抚对象**：对应我们 ⑤ 头领宠物 + 每章的关口。我们雾的设定可以变成「被雾控制、需要安抚的岛之主」。
- **骑乘 = 区域通关奖励 = 新的移动方式**：我们以后可以做「镇抚后宠物带你跨过某种地形」，和现在的探索技能（涉水、开路）一致。
- **全图鉴 = 最终目标**：是很好的长期目标，但我们宠物少（现在 6 种），要等内容多了才成立。
