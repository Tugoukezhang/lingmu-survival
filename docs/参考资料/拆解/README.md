# 参考游戏流程拆解

**这是什么**：把参考游戏的「骨架」——主线目标、解锁顺序、每段玩多久、内容有多少、通关后玩什么——拆出来，作为我们设计完整流程（`docs/12_完整流程.md`）的依据。以后设计新系统前先翻这里。

**规则**
- 全部用我们自己的话写，只记规则、数字、结构这类事实，并附原页面链接；不搬原文、不搬图（这些 wiki 多为非商业许可，见 `../wiki原文/README.md`）。
- 每条标来源可靠度：**【已核对】** 读过 wiki 原页面或多个来源一致；**【摘录】** 来自搜索结果里的 wiki 摘录；**【待核对】** 凭印象写的，等负责人存下原页面后核对。
- 只借思路，不照搬名字、角色、画面（原创要求见 CLAUDE.md）。

## 四款游戏的共同点（我们缺的就是这些）
1. **一个看得见的大目标**，并且分成几段：社区中心 6 个房间、阿尔宙斯 5 个区域、浮岛物语 5 种地貌。
2. **每完成一段，世界就变大一点**：开新区域、新设施、新航线。玩家能感觉到「往前走了」。
3. **收集清单**：收集包、图鉴、收藏馆。日常玩法产出的东西有地方交，长期有事做。
4. **每段有一个关口**：首领、王、地牢 Boss，给这一段收尾。
5. **通关后还能玩**：开放式经营、全收集、无尽挑战。
