## 二、玩法上最值得借的：宠物生态（排进"玩法"那一步）【建议】

现在野生宠物只会站着、走两步；家里的伙伴也只是跟着。参考 15 的感觉是"这个世界里本来就住着它们"：

1. **按属性住在不同地方**：水属性在池塘边、会游泳；森属性在树下、会吃果子；光属性在花丛、白天出没；暗属性在树荫里、傍晚才出来；会飞的偶尔从天上掠过。
2. **野生宠物有小动作**：吃东西、打盹、互相追、看见玩家竖耳朵。偷袭（从背后靠近）因此更有意思。
3. **家园的伙伴有生活**：在家园随处走、在营火边打盹、去农田"帮忙"、和别的伙伴玩；好感高的会跑来迎接。
4. **发现记录**：图鉴里记"在哪里、什么时间见过"，引导玩家在不同时间去不同地方。

## 三、场景那一步的清单（参考 9、10、11、5）【建议】

按手机能跑的顺序：
1. 岛边瀑布落进云海（滚动贴图 + 水雾粒子），远处几座挂碎石的小浮岛（远景面片），天上偶尔飘过的飞艇 / 鸟群。
2. 树影斑驳（树冠投影或光照贴图）。
3. 远处薄雾 + 斜光束（高度雾 + 面片光束）。
4. 风吹树梢、草叶摆动（顶点动画）。
5. 光点 / 花瓣飘浮（少量粒子，傍晚多一点）。
6. 水边白沫、水底光纹（池塘）。
7. 景深只在标题页和拍照时用（手机太贵）。
