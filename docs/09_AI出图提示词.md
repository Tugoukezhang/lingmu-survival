# AI 出图提示词（GPT Image 2.6）

版本：0.1｜日期：2026-11-08｜分工【已确认】：负责人用 GPT Image 2.6 出图；AI（Claude）写提示词、检查、抠图、统一尺寸、命名、接入游戏。

## 1. 出图流程
1. 每次出图都**上传 2 张参考图**：`docs/参考资料/风格示例/01_标题页.jpg` 和 `06_家园布置.jpg`（出界面元素时换成 `04_背包.jpg`）。
2. 复制下面第 2 节的「风格段落」+ 具体素材的提示词，一起发给 GPT Image。
3. 尺寸选正方形（1024×1024）；宠物、物品一次只出一个。
4. 满意的图下载后放进仓库的 `art/raw/` 文件夹，文件名按 `03_素材规范.md` 的命名规则（例如 `pet_fox_idle_01.png`），不确定就随便起名，告诉我是哪个素材。
5. 我来检查：风格是否和示例一致、比例、视角、光照方向、白底是否干净。不达标会给出具体问题和改好的提示词；抠图、调色、尺寸、轻微瑕疵我直接修，处理好的放进 `game/assets/`。
6. **先定造型再量产**：每只宠物先出 1 张「待机正面」，负责人和我都满意后，再拿这张当参考图出行走、攻击等其他动作，保证同一只宠物长得一样。

`art/raw/` 不提交到仓库（原图太大）；处理后的素材提交。

## 6. 不达标时怎么改（常见问题）
| 问题 | 改法 |
|---|---|
| 画风太写实 / 太平面 | 在风格段落后加「更圆润、更像参考图的手绘 3D 渲染质感」，并确认上传了参考图 |
| 背景不是纯白、有阴影地面 | 加「纯白背景，不要地面，不要投影」；轻微的我可以直接去掉 |
| 同一只宠物几次出图长得不一样 | 用已确认的那张当参考图，提示词写「保持和参考图里的角色完全一致，只改变动作为____」 |
| 出现文字或水印 | 重出；提示词里已有「不要文字水印」，可在末尾再强调一次 |
| 太吓人 | 加「更可爱、更圆、眼睛更大、表情开心」 |
