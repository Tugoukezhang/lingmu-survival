# 14 3D 试验（2026-11-11）

## 为什么做
负责人对照风格示例（`参考资料/风格示例/05_游戏内HUD.jpg`、`06_家园布置.jpg`）后认为现在的 2D 俯视画面差得远，决定**现在就转 3D**（「不一开始就 3D，后面不好改」）。这是方向决定：负责人 2026-11-11 选了路线 B（换 3D，自己用 AI 做模型，不请外包）。

## 技术路线【建议，AI 定】
- **Three.js（r170，放在 `game/vendor/three/`）**，不用 Unity。原因：Unity 要有人在编辑器里用鼠标摆场景、调动作；Three.js 全靠代码，AI 可以自己做、自己用自动检查验证。仍然是网页技术，Capacitor 打包方式不变。
- **规则和界面不动**：`systems/`、存档、Phaser 的 HUD / 面板 / 对战照旧。只换「画世界」这一层：`game/src/view3d/World3D.js` 每帧读取 PlayScene（地面贴图、每个物件的位置、光源、时间），用 3D 画出来；Phaser 画布透明地叠在上面。
- **第一步 = 饥荒的做法**：真 3D 的地面、镜头、光照、投影、雾；宠物、人物、树、房子先用现有的 2D 图立在场景里、始终面向镜头。之后逐步换成真 3D 模型。

## 怎么打开
网址后面加 `?3d=1`，例如 `http://127.0.0.1:8000/?3d=1`（演示存档：`?demo=1&3d=1`）。不加就是原来的 2D。

## 现在有什么（第一版）
- 镜头压低跟在主角身后（俯角约 37°），近大远小，看得到地平线和云海。
- 太阳光 + 天空光，物件在地上有真实的投影；远处有雾气的层次。
- 昼夜：天色、阳光随时间变；夜里营火、路灯、火把是真的光源，照亮周围的地面和角色。
- 挡在主角和镜头之间的大物件（树、房子、飞艇）自动变半透明。
- 名字标签、招牌、野生宠物等级浮在物件上方，大小不随远近变化。
- 雾怪的红色预警圈、农田可开垦的格子提示已搬到 3D。
- 家园、远征岛、小镇都能用；**小屋室内暂时还是 2D**。
- 自动检查：浏览器检查里加了 2 项 3D 模式检查（世界由 3D 画出、照常移动）。

## 还没有的（诚实清单）
- 地面是一张平的贴图：没有高低起伏，岛的侧面（悬崖）是画上去的，不是立体的；池塘是平的。
- 所有物件都是「立牌」：镜头不能转，走近看房子是一张图。
- 主角和宠物没有走路动作（2D 时也没有）。
- 野生宠物头上的「发现条」还没搬过来（「!」有）。
- 室内、对战场景还是 2D。
- 手机上的帧率没测过（我这边的自动截图用的是没有显卡的软件渲染，只有 3 帧 / 秒，不能说明问题；负责人电脑和手机有显卡，需要实际看）。

## 3D 样张（2026-11-12，对照风格示例 05）
负责人看了第一版认为差得远、希望尽量复刻风格示例。第一版只是「把 2D 图立起来」，所以单独做了一个样张场景，照着 `参考资料/风格示例/05_游戏内HUD.jpg` 逐项做，**全部是代码生成的真 3D 模型**：
- 页面：`game/look3d.html`（WASD / 方向键走动；`?shot=1` 固定姿势截图；`?q=low` 关掉环境光遮蔽和移轴，给弱机器用）。代码：`game/src/view3d/look/`（`nature.js` 石头、大叶植物、雏菊、三叶草、草丛、小花；`hero.js` 用基本形状拼的 Q 版小人（蓝帽子、橙色辫子、红背带裤，会走路）和毛团宠物；`main.js` 场景、光照、后期）。
- 地面：起伏草地 + 蜿蜒土路；满地三叶草、草丛、白 / 粉 / 黄小花（实例化，上万株）。
- 光影：暖色阳光 + 柔和投影、天空光、环境光遮蔽（GTAO，接触处的暗影）、泛光、移轴景深、调色和暗角；ACES 色调。
- 对比图：`参考资料/3D样张对比.jpg`。

**和风格示例比，还差的（诚实清单）**
- 细节和纹理：风格示例的石头、叶子、地面都有手绘质感的纹理；样张大多是纯色加简单噪点。下一步可以用 AI 生成贴图（石头、草地、叶片）提高质感。
- 叶子种类：风格示例有好几种叶形（宽圆、锯齿、心形），样张只有一种。
- 主角：用基本形状拼的，脸、头发、衣服褶皱都很简单；要接近风格示例需要真正的 3D 角色模型和动作。
- **我们自己的 6 只宠物**：细节多，代码拼不出来，需要 3D 模型（AI 图片转模型或外包）。样张里的毛团是照着风格示例的黑色毛团做的。
- 性能：环境光遮蔽和上万株植物在手机上会吃力，需要实测后分档（`?q=low`）。

## 3D 模型来源（负责人 2026-11-12 定：AI 图片转 3D）
- 先拿焰尾狐试一只：负责人用 AI 3D 工具（首选腾讯混元 3D，备选 Tripo）把定稿图转成 GLB 模型，传到 main 的 `art/incoming/`；AI 检查、修整、接入。效果可以就推广到 6 只宠物、主角、居民。
- 同时用 GPT 出 8 张贴图（石头、草地、土路纹理，3 种叶片、雏菊、三叶草贴片）补样张质感。
- 操作说明和要上传的图：`docs/15_3D素材包/`。
- 接入已经准备好：模型放 `game/assets/models/<名字>.glb`，样张网址加 `?pet=<名字>` 就替换毛团（自动缩放、落地、朝向前进方向；支持 Draco 压缩）。用手工做的测试模型验证过加载流程。

## 下一步（负责人看过第一版后）
1. **地形立体化**：岛的侧面做成真的悬崖，地面加缓坡和台阶，水面做成会动的水。
2. **摆件换成真 3D 模型**，两个来源同时试：
   - 代码生成的低面数卡通模型（树、石头、草、栅栏这类规则的东西，AI 直接写）。
   - AI 3D 工具「图片生成模型」：用已有的摆件图当输入，负责人像出图一样跑（工具待选，先试 2–3 个免费额度）。
3. **角色和宠物**：先保持立牌，补走路 / 待机的几帧动作；之后试 AI 生成带骨骼的模型，质量够再换。
4. 室内和对战场景搬到 3D。
5. 全部通过后把 3D 设为默认，删除 2D 画法。

## 风险
- 一个人 + AI 做 3D，质量上限低于风格示例（那是大团队水准），这点已和负责人说明。
- 网页 3D 在中低端手机上的性能要尽早实测（T18 一起做）。
