## 整体气质
- 治愈、温暖、童话森林小岛；阳光感强，饱和度中高但不刺眼。
- 场景：手绘质感的 3D 渲染风（圆润造型、柔和阴影），固定 3/4 俯视角。
- 角色：Q 版大头比例，圆润；宠物是圆滚滚的小动物。

## UI 组件规范
- **面板**：奶油底 + 深棕粗边框（约 6px）+ 大圆角（约 24px）；面板角落可点缀小花和叶子。
- **关闭按钮**：右上角木头圆牌 + 白色叉，旁边小叶子。
- **返回按钮**：左上角木头圆牌 + 弯箭头。
- **页签**：圆角方块图标，选中为暖黄底或绿底。
- **格子**：奶油暗色圆角方块，右下角数量数字（描边）。
- **主按钮**：胶囊形，绿底白字或暖黄底棕字。
- **列表项**（活动列表）：深棕胶囊条 + 奶油字，选中变暖黄。
- **物品详情卡**：大图标 + 名称 + 分类标签（粉色小胶囊）+ 描述 + 一句俏皮台词 + 使用按钮。
- **HUD**：左上小地图 + 天数；任务追踪条在左侧；右上功能图标排；右下圆形快捷按钮（相机、表情、工具箱）。
- **字体**：圆润手写感中文字体；标题白字加深色描边。

## 手机横屏注意
- 逻辑分辨率 960×540，按钮最小 44×44 逻辑像素。
- 关键 UI 离屏幕边缘至少 24 逻辑像素（刘海、圆角）。
- 左下留给虚拟摇杆，右下留给动作按钮，不放其他可点元素。

## 远征与夜晚的氛围（2026-11-08 新增，参考视频笔记见 `参考资料/README.md`）
- **云海浮岛**：远征岛和家园岛都悬在云海上，岛屿边缘露出泥土/岩石的断面，下方是流动的云。
- **昼夜**：白天暖黄阳光；黄昏转橙紫；夜晚整体压暗成蓝黑色，只有光源附近恢复原色。
- **光源**：营火、火把、发光宠物周围一圈暖光，边缘柔和过渡；夜里加萤火粒子。
- **雾怪**：灰紫色、软软的雾团，有发光的眼睛；要让人有点紧张，但不能吓人（12+ 适龄）。
- **危险提示**：雾怪攻击前地面出现半透明红色圆圈，边缘清楚，在暗处也一眼能看到。
- **采集反馈**：砍树、挖石时轻微顿帧 + 碎屑飞溅 + 掉落物弹出后飞进背包。
