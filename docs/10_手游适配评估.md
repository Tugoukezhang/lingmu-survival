# 手游适配评估（2026-11-08）

负责人问：「当前的游戏逻辑用作手游是否合理」。下面按手游玩家的真实使用场景逐项评估。结论标注：✅ 合理 / ⚠️ 有风险要处理 / ❌ 上线前必须改。所有判断都是【建议】，需要真机试玩验证。

## 1. 结论

**核心玩法适合手游。**一个游戏日约 12 分钟，一趟远征（出发 → 采集 → 对战捕捉 → 回家）8–10 分钟，正好是手游一次打开的时长；随时切出去也会自动存档；操作只有摇杆 + 一个会变字的按钮 + 面板。

**上线前必须处理的有 3 件**：超宽屏两侧留白、App 里的存档方式、实名与防沉迷。**要靠试玩确认的有 3 件**：文字大小、生存惩罚强度、手机性能。另外缺少「每天回来玩」的理由，这会直接影响留存和商业化。

## 2. 逐项评估

| 项目 | 现在的做法 | 判断 | 建议 |
|---|---|---|---|
| 一次玩多久 | 一天 12 分钟；远征 8–10 分钟；可以提前睡觉跳到第二天 | ✅ | 保持。 |
| 被打断 | 切后台、关页面自动存档；对战中被打断回到战前；打开菜单时间暂停 | ✅ | 保持。 |
| 操作 | 左下摇杆、右下按钮（显示「采集 / 打开 / 出发」等），按钮触控区 ≥ 44 | ✅ | 横屏需要双手，这是这类游戏的常态。 |
| 新手引导 | 6 步「下一步目标」+ 3 条一次性提示（本次新增） | ✅ | 试玩时观察有没有人卡住。 |
| 屏幕比例 | 按 16:9 等比缩放；现在大多数手机是 19.5:9 左右，**两侧各留出约 1/10 的空白** | ❌ | 改成「宽屏多显示一点世界」：HUD 贴到真实屏幕边缘，世界视野变宽。需要调整界面布局，建议和手绘 UI（T41）一起做。 |
| 刘海 / 圆角 | 本次加了安全区，游戏画面避开刘海；HUD 离边 24 | ✅ | 真机确认。 |
| 文字大小 | 本次把最小字号提到 14（手机上约 10 像素） | ⚠️ | 仍偏小。手绘 UI 重做时正文用 16–18，标题 22+。 |
| 性能 | 电脑上 60 帧；夜晚光圈每帧重画；地面是一整张大图（家园约 16MB 显存） | ⚠️ | 负责人手机实测；卡的话改成分块地面、降低光圈分辨率。 |
| 电量 / 发热 | 一直按 60 帧渲染 | ⚠️ | 设置里加「省电模式（30 帧）」。 |
| 存档 | 浏览器本地存储（localStorage），带备份和校验 | ❌（打包时） | 打包成 App 后，iOS 在空间紧张时可能清掉网页数据 → 打包时改用原生存储（Capacitor Preferences / 文件），再加云存档（T35）。 |
| 生存惩罚 | 远征倒下：工具保留，其他东西掉进失物包，回去能捡 | ⚠️ | 手游玩家容错比 PC 低。建议先启用开工图里预留的缓解手段：**前 3 天倒下不掉东西**；T26 试玩看是否需要更多。 |
| 时间压力 | 饥饿 + 20 点起雾；一天不吃会在远征中饿倒 | ⚠️ | 节奏偏紧，试玩观察；可把饱食下降放慢到每 15 分钟 −1。 |
| 每天回来的理由 | 目前只有「过一天」本身 | ⚠️ | 手游留存靠每日目标：建议 M3 种田时一起做「每日小任务（3 个）+ 连续登录小礼物」，季节通行证（M5）也依赖它。 |
| 商业化场景 | 外观能在跟随、对战、宠物面板里看到；不卖数值 | ✅ | 通行证需要每日 / 每周任务体系支撑（同上）。 |
| 联网与合规 | 纯单机、可离线 | ❌（上线前） | 国内上架必须实名认证 + 未成年人防沉迷（限时段、限时长），需要账号系统（T35）；版号周期长，可玩版本稳定后尽早申请。 |
| 横竖屏 | 只支持横屏，竖屏显示「请横过来」 | ✅ | 保持。 |

## 3. 本次已经顺手改了

- 新手引导：6 步目标 + 3 条一次性提示，设置里可关闭。
- 刘海屏安全区。
- 清晨 6:00 原来还是黎明的深蓝色——新玩家打开游戏第一眼是暗的。改成 6:00 已经亮了（4:30 开始天亮）。
- 最小字号 14。

## 4. 建议的处理顺序

1. **负责人真机实测**（文字、手感、帧率、发热），这决定第 2、3 条做多少。
2. **宽屏适配 + 文字放大**：和手绘 UI 替换（T41）一起做，避免界面改两遍。
3. **前 3 天倒下不掉落**（缓解手段，一行规则）——需要负责人点头，因为「中度生存」是负责人确认过的。
4. **每日小任务**：M3 种田时一起做。
5. **原生存储 + 云存档 + 实名防沉迷**：打包上架前（M5，T35）。
