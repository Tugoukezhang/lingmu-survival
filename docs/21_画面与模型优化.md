## 怎么做

**A. 模型重做（Tripo 网页，AI 用浏览器插件操作）**：主角、6 只宠物、3 种树、3 位居民。建模用的图已由 GPT 按标准站姿重画，清单和设置见 `16_建模任务包/第二轮_高精度重做.md`。角色贴图上限从 1024 提到 2048。

**B. 动作**：网页能加的动作直接加；网页没有的（宠物攻击、受击、睡觉、吃东西等）在 Blender 里补。战斗里的前冲、受击闪色、击退、镜头震动用程序做。

**B2. 对战改成 3D**：现在对战里的宠物是 2D 立绘（只会滑动、抖一下）。新模型带骨骼后，对战改成两只 3D 宠物面对面：入场、待机、出招时扑过去、受击后退闪色、倒下，镜头跟着推近和震动。这是"宠物战斗动作"最大的提升，模型一到就做。按负责人的顺序，技能特效（火星、水花等）放在最后。

**C. 场景（AI 自己做，不花积分）**
1. 树和灌木随风摆动：`Shaders/LingmuFoliage.shader` + `World/Foliage.cs`。树越高的地方摆得越多，每棵树节奏不同，有阵风，树叶有细小的抖动，影子跟着摆。✅
2. 天空：换成渐变天空 `Shaders/LingmuSky.shader`（头顶深蓝、地平线偏暖、太阳周围有光晕），GPT 画的大积云和远处的小浮岛（带瀑布）做成天空里的卡片（`Resources/Sky/`、`Shaders/LingmuSkyCard.shader`），慢慢飘。✅
3. 雾改成偏蓝、从 45 米开始，远处不再发白。✅
4. 视角：双指捏合 / 鼠标滚轮拉近拉远（3.6–11 米）。✅
5. 飘浮的光点：玩家身边有细小的光点慢慢飘，傍晚更多。✅
6. 泛光调低：原来的泛光把下面大片的云海都算进去，整个画面像蒙了一层白纱、颜色发灰。阈值 0.95 → 1.15，强度 0.45 → 0.28。✅
7. 之后：光束、水面颜色、草的质感、建筑贴图精度、新树模型到了以后换上。
